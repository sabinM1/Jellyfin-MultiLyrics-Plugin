Multi-Lyrics

Queries lyric sources in the priority order set below, prefers synced (.lrc) results over plain (.txt) ones, and holds the lyrics of the current track in memory. Results are fetched on demand and are never written to a library folder or to Jellyfin's metadata folder.

Log lines from this plugin start with Multi-Lyrics — see Dashboard → Logs. Jellyfin reports the loaded version at startup as Loaded plugin: Multi-Lyrics <version>.

Settings page build 1.0.0.1. This page is embedded in Jellyfin.Plugin.MultiLyrics.dll, so the number here is the version of the assembly Jellyfin loaded. If the dashboard lists a newer plugin version than the one shown here, reload the page with Ctrl+F5.

Source priority

Lower numbers are asked first. A synced result ends the search; a plain result is kept as a fallback while the remaining sources are still tried for a synced one. Unticked sources are skipped entirely, except LRCLIB which is always enabled. Each priority number must be used exactly once.

Enabled Source Priority
Synced and plain lyrics, no API key — always enabled
Plain lyrics, no API key
Plain lyrics, unofficial page scrape
Lyric text scraped from the song page (see the legal note)

LRCLIB cannot be disabled: it is the primary source of synced lyrics.

On (default): a synced result wins even when a higher-priority source returned plain text. Off: the order is literal — the first source with any lyrics wins, which is how a plain source (Genius, Tekstowo) becomes the one you see.

Genius

Genius legal note: lyric text is only obtainable by scraping the song page, which may violate the Genius Terms of Service — personal use only. Enabling Genius above puts it in the priority queue as a plain (scraped) source, at the position you gave it. Cloudflare challenges are treated as a miss and are never stored as lyrics. A client access token is optional: without one the plugin searches the public genius.com page instead of the official API.
Optional: scraping the song page needs no token. With one, the search step uses the official API (genius.com/api-clients); without one the public genius.com search is queried. Stored in Jellyfin's plain-text plugin XML because plugins have no secret store; never logged by the plugin.
